# ADR 0005 — next-intl : français par défaut, arabe RTL, anglais

Statut : accepté (2026-10-20)

Segment `[locale]`, `localePrefix: "as-needed"` (`/` en français, `/ar`,
`/en`). `<html lang dir>` posés par le layout ; mise en page en propriétés
logiques Tailwind (`ms-`, `pe-`, `border-e`, `text-start`). Police arabe
IBM Plex Sans Arabic, chiffres latins partout (usage marocain). Dates
jj/mm/aaaa dans le fuseau Africa/Casablanca quelle que soit la langue
(`lib/format.ts`). Le décalage horaire vient des données tz du runtime, jamais d'une constante : tzdata 2025b donne UTC+1 pour Casablanca, tzdata 2026c donne UTC+0 — garder Node à jour, ne jamais figer un décalage dans le code ni dans un test. Tests : parité des clés et des variables fr/ar/en,
typographie française (espaces fines insécables, apostrophe typographique).
Chemins encore en français dans les trois langues : chemins localisés à
décider en phase 3 (SEO).
